Crimping Kabel LAN (UTP)

Praktikum Jaringan Dasar • Kelas X TKJ • AZZ Hub
Estimasi Waktu
60 Menit
Tingkat
Dasar
Kelompok
2-3 Orang
Alat & Bahan
Kabel UTP Cat5e/Cat6 Crimping Tool Connector RJ-45 Cable Tester Cutter/Stripper Penggaris
Urutan Warna Kabel
Straight-Through (T568B)
Putih-OrangePin 1
OrangePin 2
Putih-HijauPin 3
BiruPin 4
Putih-BiruPin 5
HijauPin 6
Putih-CoklatPin 7
CoklatPin 8
Cross-Over (T568A → T568B)
Putih-HijauPin 1
HijauPin 2
Putih-OrangePin 3
BiruPin 4
Putih-BiruPin 5
OrangePin 6
Putih-CoklatPin 7
CoklatPin 8
Langkah Praktikum
1
Persiapan & Pengukuran Kabel
Siapkan kabel UTP sepanjang yang diperlukan (minimal 1 meter untuk latihan). Gunakan cutter untuk memotong kabel dengan bersih.
Ilustrasi: Pengukuran kabel UTP
2
Kupas Outer Jacket
Kupas lapisan luar kabel (outer jacket) sepanjang ± 2-3 cm menggunakan stripper tool atau crimping tool. Hati-hati jangan sampai merusak isolasi kabel dalam.
3
Pisahkan & Luruskan Kabel
Pisahkan 4 pasang kabel twisted pair. Luruskan setiap kabel dan urutkan sesuai standar T568B untuk kabel straight-through.
Ilustrasi: Pengurutan kabel warna
4
Potong Rata Kabel
Setelah kabel diurutkan dengan benar, potong ujung kabel secara rata menggunakan crimping tool. Panjang kabel yang keluar dari jacket ± 1.2 cm.
5
Masukkan ke Connector RJ-45
Masukkan kabel yang sudah diurutkan ke dalam connector RJ-45. Pastikan setiap kabel masuk ke jalurnya masing-masing dan ujung kabel menyentuh bagian tembaga connector.
Ilustrasi: Memasukkan kabel ke connector RJ-45
6
Crimping dengan Crimping Tool
Masukkan connector ke crimping tool dan tekan dengan kuat hingga terdengar bunyi "klik". Pastikan semua pin tembaga connector menusuk isolasi kabel.
7
Test dengan Cable Tester
Masukkan kedua ujung kabel ke cable tester. LED indicator harus menyala berurutan 1-8. Jika salah urutan atau ada yang tidak menyala, proses crimping harus diulang.
Ilustrasi: Pengujian dengan cable tester
Perhatian: Pastikan urutan warna kabel benar sebelum di-crimp. Setelah di-crimp, tidak bisa diubah tanpa memotong connector.
Penggunaan Kabel: Straight-through untuk PC↔Switch, PC↔Hub. Cross-over untuk PC↔PC, Switch↔Switch (non-uplink), Router↔Router langsung.

Konfigurasi Dasar MikroTik

Internet Sharing & DHCP Server • Kelas XI TKJ • AZZ Hub
Waktu
90 Menit
Tingkat
Menengah
Kelompok
2-3 Orang
MikroTik RouterBoard Winbox App Kabel LAN (Straight) PC/Laptop Modem ISP
Topologi Praktikum
Internet → Modem → ether1 [MikroTik] ether2 → Switch → PC Client
Langkah Konfigurasi
1
Koneksi Fisik & Reset MikroTik
Hubungkan: Modem ISP → ether1 MikroTik, PC/Laptop → ether2 MikroTik. Reset MikroTik ke factory default jika diperlukan.
Reset via tombol RESET di perangkat, atau:
[admin@MikroTik] > /system reset-configuration
2
Login via Winbox
Buka Winbox, klik "Neighbors" untuk scan, pilih MikroTik, login dengan username admin, password kosong.
3
Set IP Address WAN (ether1)
Konfigurasi IP address untuk interface WAN (ether1) yang terhubung ke modem/ISP. Bisa menggunakan DHCP client atau IP statis.
# Jika ISP menggunakan DHCP
/ip dhcp-client add interface=ether1 disabled=no

# Jika menggunakan IP Statis
/ip address add address=192.168.0.2/24 interface=ether1
/ip route add gateway=192.168.0.1
4
Set IP Address LAN (ether2)
/ip address add address=192.168.1.1/24 interface=ether2
5
Konfigurasi NAT (Internet Sharing)
/ip firewall nat add chain=srcnat out-interface=ether1 action=masquerade
6
Konfigurasi DHCP Server
/ip pool add name=dhcp-pool ranges=192.168.1.100-192.168.1.200
/ip dhcp-server add name=dhcp1 interface=ether2 address-pool=dhcp-pool disabled=no
/ip dhcp-server network add address=192.168.1.0/24 gateway=192.168.1.1 dns-server=8.8.8.8
7
Set DNS
/ip dns set servers=8.8.8.8,8.8.4.4 allow-remote-requests=yes
8
Verifikasi & Test
Test koneksi internet dari PC client. PC harus mendapat IP dari DHCP dan bisa akses internet.
# Test di MikroTik
/ping 8.8.8.8

# Di PC Client (CMD)
ipconfig
ping 8.8.8.8
ping google.com

Download & Persiapan ISO

Address: 192.168.1.10

Name Servers: 8.8.8.8, 8.8.4.4

Partisi Disk
Untuk praktikum, pilih "Use entire disk" untuk partisi otomatis. Konfirmasi dan lanjutkan instalasi.
6
Buat Akun User

Server name: tkj-server
Username: tkjadmin
Password: (buat password kuat)
7
Install OpenSSH Server

Proses Instalasi & Reboot

Konfigurasi DHCP Server (ISC DHCP)

Linux Server • Ubuntu/Debian • Kelas XI TKJ • AZZ Hub
1
Instalasi ISC DHCP Server
sudo apt update
sudo apt install isc-dhcp-server -y
2
Set Interface DHCP
sudo nano /etc/default/isc-dhcp-server

# Ubah baris INTERFACESv4:
INTERFACESv4="ens33"
# Ganti ens33 dengan nama interface Anda
# Cek interface: ip addr
3
Konfigurasi DHCP Server
sudo nano /etc/dhcp/dhcpd.conf

# Tambahkan konfigurasi:
default-lease-time 600;
max-lease-time 7200;
authoritative;

subnet 192.168.1.0 netmask 255.255.255.0 {
  range 192.168.1.100 192.168.1.200;
  option routers 192.168.1.1;
  option domain-name-servers 8.8.8.8, 8.8.4.4;
  option broadcast-address 192.168.1.255;
  option domain-name "tkj.local";
}

# IP Statis untuk perangkat tertentu:
host printer {
  hardware ethernet AA:BB:CC:DD:EE:FF;
  fixed-address 192.168.1.50;
}
4
Start & Enable Service
sudo systemctl start isc-dhcp-server
sudo systemctl enable isc-dhcp-server
sudo systemctl status isc-dhcp-server
5
Verifikasi DHCP Lease
# Lihat DHCP lease yang aktif
cat /var/lib/dhcp/dhcpd.leases

# Atau monitor log
sudo journalctl -u isc-dhcp-server -f

Pengenalan Fiber Optik & Komponen

Fiber Optik Dasar • Kelas XI TKJ • AZZ Hub
1
Identifikasi Jenis Kabel Fiber
Identifikasi kabel fiber berdasarkan warna jacket: Kuning = Single Mode, Orange/Aqua = Multi Mode. Perhatikan label pada kabel (9/125 untuk SMF, 50/125 atau 62.5/125 untuk MMF).
2
Identifikasi Connector
Kenali jenis connector: SC (kotak besar), LC (kotak kecil), FC (bulat dengan ulir), ST (bayonet), MTP/MPO (banyak fiber).
Ilustrasi: Berbagai jenis connector fiber optik
3
Pembersihan Connector
Bersihkan connector sebelum digunakan menggunakan fiber cleaning pen atau tisu alkohol. Debu bisa meningkatkan redaman secara signifikan.
4
Inspeksi dengan Fiber Scope
Gunakan fiber scope atau VFL (Visual Fault Locator) untuk memeriksa kebersihan dan kondisi ujung fiber. JANGAN melihat fiber aktif langsung!
BAHAYA! Jangan pernah melihat ujung fiber optik aktif dengan mata telanjang. Sinar laser dapat merusak retina permanen!

Fusion Splicing Fiber Optik

Teknik Penyambungan Fiber • Kelas XII TKJ • AZZ Hub
Fusion Splicer Fiber Cleaver Fiber Stripper Alkohol 99% Tisu Optik Heat Shrink
1
Strip Jacket & Buffer
Kupas outer jacket sepanjang ±5 cm, lalu kupas buffer/coating sampai tersisa serat kaca mentah. Gunakan fiber stripper yang tepat untuk setiap lapisan.
2
Bersihkan Serat Kaca
Basahi tisu optik dengan alkohol 99% (IPA). Bersihkan serat dari pangkal ke ujung dengan sekali usap. Jangan mengulang usapan yang sama.
3
Pasang Heat Shrink Sleeve
Sebelum cleave, masukkan heat shrink sleeve ke salah satu sisi fiber. Ini penting karena tidak bisa dipasang setelah di-splice.
4
Cleave Fiber
Masukkan fiber ke fiber cleaver, tekan tuas cleave dengan halus. Hasil cleave yang bagus: sudut 89.5°-90°, permukaan rata tanpa retakan.
5
Proses Fusion Splicing
Masukkan kedua fiber ke slot fusion splicer. Tutup cover dan jalankan proses fusion (mode otomatis). Splicer akan menyelaraskan dan menyambung fiber dengan panas elektrik.
Estimasi Loss yang Ditampilkan Splicer:
Target: < 0.02 dB (excellent)
Baik  : < 0.05 dB (good)
Max   : < 0.10 dB (acceptable)
6
Lindungi dengan Heat Shrink
Geser heat shrink sleeve ke titik splice. Masukkan ke heat oven splicer selama ±60 detik. Heat shrink akan mengencang dan melindungi splice.
7
Verifikasi dengan OTDR/OPM
Uji hasil splice menggunakan OTDR untuk melihat lokasi dan redaman, atau OPM untuk mengukur total loss.

Penggunaan OPM (Optical Power Meter)

Pengukuran Redaman Fiber Optik • Kelas XII • AZZ Hub
1
Persiapan OPM
Nyalakan OPM dan pilih wavelength yang sesuai: 1310nm atau 1550nm untuk Single Mode, 850nm untuk Multi Mode.
2
Kalibrasi (Reference Level)
Sambungkan OLS (Optical Light Source) ke OPM dengan kabel reference yang bersih. Catat nilai referensi ini sebagai baseline 0 dB.
Contoh: Reference power = -10 dBm
Ini menjadi titik 0 dB pengukuran
3
Pengukuran Redaman
Sambungkan OLS ke satu ujung link fiber yang akan diukur. Sambungkan OPM ke ujung lainnya. Baca nilai yang ditampilkan OPM.
Rumus:
Loss (dB) = Reference Level - Measured Level

Contoh:
Reference: -10 dBm
Measured : -13 dBm
Loss      = -10 - (-13) = 3 dB
4
Standar Redaman
Budget redaman yang acceptable:
• Splice loss    : < 0.1 dB per splice
• Connector loss : < 0.5 dB per connector
• Total fiber    : 0.2-0.35 dB/km (SMF @1310nm)
• Margin safety  : 3 dB minimum

Penggunaan OTDR

Optical Time Domain Reflectometer • Kelas XII • AZZ Hub
1
Pengenalan OTDR
OTDR (Optical Time Domain Reflectometer) mengirim pulsa cahaya ke fiber dan menganalisis cahaya yang dipantulkan balik untuk mendeteksi event (splice, connector, kerusakan) dan lokasinya.
2
Persiapan & Setting OTDR
Setting dasar OTDR:
• Wavelength: 1310nm atau 1550nm
• Range     : Sedikit lebih dari panjang fiber
• Pulse width: Disesuaikan dengan range
• Average   : 16-64 scans untuk akurasi
• Refractive index: 1.4682 (SMF standard)
3
Gunakan Launch Cable
Selalu gunakan launch cable (kabel pigtail 50-100m) sebelum fiber yang diuji. Ini untuk menghindari "dead zone" di awal pengukuran yang bisa menyembunyikan event pertama.
4
Membaca Trace OTDR
Interpretasi Hasil OTDR:
• Garis miring ke bawah = serat fiber (loss per jarak)
• Spike ke atas (reflective) = connector/connector
• Step ke bawah (non-reflective) = splice/macrobend
• Spike tajam ke bawah di akhir = ujung fiber (end)

Informasi yang dibaca:
• Jarak event dari OTDR
• Loss di setiap event (dB)
• Return loss (dB)
• Total loss sepanjang fiber
5
Laporan & Dokumentasi
Simpan hasil pengukuran ke memory OTDR atau export ke PC. Dokumentasikan setiap event dengan lokasinya untuk keperluan maintenance di masa depan.
Penting: Pastikan tidak ada perangkat aktif (transceiver SFP) di ujung fiber saat menggunakan OTDR, karena bisa merusak perangkat aktif tersebut.
